Step 1> Open the terminal by right clicking the index.js in the main directory of the folder and choose "open in integrated terminal.

Step 2> Set the app by typing in "npm run init_tables" in the terminal.

Step 3> Run the app by typing in "npm run dev" in the terminal.

Now the app is running and it can be proven by checking "App listening to port http://localhost:3000/index.html" in the terminal.
